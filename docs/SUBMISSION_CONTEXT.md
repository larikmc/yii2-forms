# Контекст страницы и объекта в yii2-forms

С версии с этим патчем формы могут автоматически сохранять сведения о странице, а также передавать прикладной контекст (ID, тип и название базы, товара, услуги). Работает для обычной и модальной формы, в том числе при нескольких формах на одной странице.

## Что собирается автоматически

- Абсолютный URL страницы **без query string и fragment** (во избежание утечки токенов и персональных данных из URL).
- Заголовок страницы (`Yii::$app->view->title`, если заполнен).
- Yii2 route контроллера.

## Пример: форма на странице базы

```php
<?= \larikmc\forms\widgets\FormModalWidget::widget([
    'formId' => 4,
    'buttonLabel' => 'Запросить обновление',
    'context' => [
        'object_type' => 'database',
        'object_id' => (int) $model->id,
        'object_title' => $model->title,
    ],
]) ?>
```

Для обычного виджета:

```php
<?= \larikmc\forms\widgets\FormWidget::widget([
    'formId' => 2,
    'context' => [
        'object_type' => 'service',
        'object_id' => 7,
        'object_title' => 'Парсинг на заказ',
    ],
]) ?>
```

Если `context` не передан, URL, заголовок и маршрут страницы всё равно собираются автоматически.

## Настройки модуля

По умолчанию используется `Yii::$app->request->cookieValidationKey`. Рекомендуется установить отдельный секрет из окружения, не помещая его в репозиторий:

```php
'modules' => [
    'forms' => [
        'class' => \larikmc\forms\Module::class,
        'contextSigningKey' => getenv('FORMS_CONTEXT_KEY') ?: null,
        'contextTtl' => 2592000, // 30 дней
    ],
],
```

Если нет ни отдельного ключа, ни `cookieValidationKey`, контекст не создаётся (сама форма работает как прежде).

`contextTtl` задаёт срок в секундах; значение `0` отключает срок действия, что может потребоваться при длительном HTML-кешировании. При истечении токена сохраняется сама заявка, но не её контекст. При использовании полного HTML-кеширования рекомендуется учитывать срок действия подписи.

## Интеграция в свой шаблон формы

В собственном шаблоне вставьте внутри `Html::beginForm()`:

```php
<?= \yii\helpers\Html::hiddenInput('_forms_context', $signedContext ?? '') ?>
```

Штатный шаблон дополнен автоматически. При нескольких виджетах токены отличаются, поскольку формируются для каждого вызова виджета.

## Где смотреть результат

- В админке в списке заявок — колонка «Источник заявки».
- В карточке заявки — отдельный раздел «Контекст страницы и объекта».
- В email-уведомлении — отдельный раздел с теми же значениями.
- В БД: `forms_submission.context_json`, отдельно от `data_json` с ответами посетителя.

## Безопасность

Подпись HMAC формируется сервером Yii2 при создании формы и проверяется на отправке. Токен привязан к ID формы и имеет ограниченный срок действия; изменение полей `object_id` или `object_title` в браузере приводит к недействительной подписи.

Контекст — **публичные сведения о странице**, а не удостоверение полномочий пользователя. Не помещайте туда секреты или чувствительные данные. Для действий с заказами, доступом к данным или оплатой по-прежнему требуется полноценная серверная проверка авторизации и актуального состояния объекта.

## Миграция

```bash
php yii migrate --migrationPath=@vendor/larikmc/yii2-forms/src/migrations
```

В локальной разработке расширения применяйте миграции из реального пути, по которому Composer установил пакет. Перед миграцией сделайте резервную копию БД.
